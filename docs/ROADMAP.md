# Product roadmap

## v0.1 — shipped in this package

Local dashboard; repository-level project, feature and review records; tool doctor; guided setup; 10 skill contracts; Hermes conversational CLI launcher; GitHub Actions; tests.

## v0.2 — next acceptance target

Real Hermes conversation panel via authenticated local backend, task orchestration and Codex execution adapter, launch status, logs, cancellation, cost limits, independent review evidence and GitHub PR integration. Owner must be able to start one complete feature slice from dashboard and see actual passing CI before acceptance.

## v0.3 — personal operating HQ

Knowledge vault, searchable memory, reminders, schedules, connectors, approval queue for tool actions, event stream and notifications. Single-user private access only.

The optional Infinite Arch headquarters shell now reads local status, tasks, schedules, runs, and approvals, and can save a proposed agent definition for Git review. It does not launch adapters from the browser.

## v0.4 — Mac mini portability

Signed bootstrap/release workflow, backup/restore, `launchd` services, private remote access, monitoring and real device recovery drill.

## Future

Multiple machines, models, agent providers, reliable multi-user controls, permissions, per-project budgets and pluggable business workflows.
