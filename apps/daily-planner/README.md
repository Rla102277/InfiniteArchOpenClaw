# Daily Planner

A reusable board for priorities such as “Choose today's first task.” Each local record has a title, status, and note. No calendar or personal schedule is included.

`app.json` uses the shared record-board renderer and `local.records` permission. Planning does not send reminders, synchronize a calendar, or run an agent. Keep records private and consult [the scheduler contract](../../system/contracts/SCHEDULER.md) before enabling a local digest schedule.
