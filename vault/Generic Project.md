# Generic Project

Example outcome: create a small reusable checklist board. This is an illustrative pattern, not a person's active project or approval.

1. Ask which outcome would make the board useful.
2. Select the Project Board template and propose a generic title and description.
3. Preview the fixed `title`, `status`, and `note` fields and `local.records` permission.
4. Obtain explicit approval for the exact declaration before writing it.
5. Verify the board through the shared renderer, store records privately, and record evidence in a private [[Handoff]].

Do not include real contacts, schedules, financial records, locations, or account details as examples. Follow [[Governance]] and the [builder contract](../system/contracts/BUILDER.md); reusable lessons may enter [[Memory]] only after generalization and approval.
