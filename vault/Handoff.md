# Handoff

A reusable handoff explains the approved objective, current revision, files owned, actual changes, observed verification with exit codes, unknowns, rollback, and next decision. Preserve that shape when switching implementers or machines.

Place actual session history, private evidence, identities, and backup locations in external local storage. The reusable [[Brain]] contains the pattern only. Label each claim observed, inferred, unverified, or proposed; a planned check is not passing evidence.

Use [the integration handoff](../docs/HANDOFF.md) for this source slice. Keep [[Governance]] and [[Memory]] boundaries intact when preparing a packet for manual transfer to another implementer.
