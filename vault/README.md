# Canonical Brain

This Obsidian-compatible vault contains reusable definitions and semantic memory. Open `vault/` as a vault; ordinary Markdown and wikilinks such as [[Brain]] work without a plugin or account. No `.obsidian` settings, credentials, device paths, or personal notes are required.

Start with [[Brain]], [[Memory]], [[Governance]], [[Daily Workflow]], and [[Handoff]]. [[Generic Project]] illustrates a reusable planning pattern without private examples.

The GitHub-reviewed vault is the portable brain. Personal observations, app records, drafts, conversations, and operational evidence stay in the external private data root described in [the storage contract](../system/contracts/STORAGE.md). Do not automatically synchronize private memory into this vault. Promote only a generalized, reviewed, explicitly approved lesson.

Wikilinks connect concepts; they never authorize tools. Frontmatter labels scope and purpose, not privileges. Contracts in `system/contracts/` are the precise interfaces; runtime tests establish which behaviors are actually enforced.
