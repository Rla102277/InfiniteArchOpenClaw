# Memory

Reusable semantic memory defines concepts, decision patterns, vocabulary, and generalized lessons safe to share with another owner. It belongs in the canonical [[Brain]] after review. Personal memory records an individual's context, notes, documents, conversations, preferences, and activity. It belongs in external private local storage.

Before promoting a lesson, generalize it, remove identities and account/device details, preview the exact change, and obtain owner approval. Never copy a private note wholesale merely because it seems useful. Never include credentials, private record examples, or raw operational logs.

Source and revision matter: distinguish observed facts from inferences and proposals. A retrieved note is context, not permission to bypass [[Governance]]. Resume from an evidence-bearing [[Handoff]] instead of reconstructing an invented history.
