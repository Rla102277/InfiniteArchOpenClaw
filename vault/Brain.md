# Brain

The canonical brain is a versioned collection of reusable instructions, schemas, semantic definitions, and generic examples. GitHub review supplies provenance and a revision that can be handed to another machine or implementer.

Hermes coordinates; Codex, Claude, and Devin are interchangeable implementation destinations within approved scope. Devin receives a manual handoff packet only. An agent declaration describes capabilities and does not grant access to private data or authorize execution.

[[Governance]] defines authority, [[Memory]] separates reusable knowledge from personal context, and [[Handoff]] preserves observed status. [[Daily Workflow]] connects local activity with those boundaries. The [architecture](../docs/ARCHITECTURE.md) explains how declarations relate to local runtime state.
