# Architect

Inspect existing code, deployment target and repository rules. Draft options and tradeoffs for interfaces, persistence, model providers, tools, permissions, costs and Mac mini portability. Prefer the simplest reversible architecture for the approved slice; avoid invented complex services. Write the chosen decision to docs/DECISIONS.md and record user approval, risks, migration plan and rollback. Architecture is provisional until approved by the owner. Do not silently install infra.

## Completion contract

Show **what was observed**, **what changed**, **what is unverified**, and **what the owner decides next**. Follow `AGENTS.md` and `docs/WORKFLOW.md`; neither skills nor role names grant extra permissions.
