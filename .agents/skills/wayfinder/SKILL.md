# Wayfinder

Given an idea with many moving parts, inspect existing context and identify desired outcome, unknowns, dependency order and irreversibility. Map 2-3 viable approaches and tradeoffs; use a small prototype when that would answer the biggest uncertainty. Produce projects/<slug>/docs/ROADMAP.md with milestones, first usable end-to-end slice, acceptance demos, dependencies, and explicit stop conditions. Present the plan in ordinary language and ask approval before committing major architecture choices. No code implementation here.

## Completion contract

Show **what was observed**, **what changed**, **what is unverified**, and **what the owner decides next**. Follow `AGENTS.md` and `docs/WORKFLOW.md`; neither skills nor role names grant extra permissions.
