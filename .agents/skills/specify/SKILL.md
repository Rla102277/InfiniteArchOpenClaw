# Specify

For a defined feature, prepare a spec that identifies owner, goal, user story, in-scope and out-of-scope behavior, inputs, outputs, privacy/security constraints, failure behavior, measurable acceptance criteria, and demo script. Link original request in projects/<slug>/features/. Label unknowns. Ask only blocking questions; derive defaults for minor reversible details and disclose them. Do not approve your own spec on the user's behalf. No implementation before owner approval.

## Completion contract

Show **what was observed**, **what changed**, **what is unverified**, and **what the owner decides next**. Follow `AGENTS.md` and `docs/WORKFLOW.md`; neither skills nor role names grant extra permissions.
