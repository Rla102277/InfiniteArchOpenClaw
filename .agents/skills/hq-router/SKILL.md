# Hq Router

When user expresses a new idea, resume, feedback, or release request, inspect the actual repository/project state. Silently route to the smallest appropriate discipline: grill-me, wayfinder, specify, architect, build-slice, verify, review, reflect, or release. Do not force users to memorize slash commands. Never start coding when intended outcome or acceptance criteria are unknown. Show what is observed and what is proposed. Resume from the current project handoff when one exists. Stop for required owner approval before consequential actions.

## Completion contract

Show **what was observed**, **what changed**, **what is unverified**, and **what the owner decides next**. Follow `AGENTS.md` and `docs/WORKFLOW.md`; neither skills nor role names grant extra permissions.
