# Reflect

Read decisions, CI results, review notes and owner demo feedback. Write concise docs/HANDOFF.md: verified current state, pending work, exact branch/ref, blockers, next safe command and decisions. Propose permanent structural corrections through tests, tooling and architecture before expanding prompt text. Changes to shared skills require separate review and approval. Never erase previous lessons or claim behavior was verified without evidence.

## Completion contract

Show **what was observed**, **what changed**, **what is unverified**, and **what the owner decides next**. Follow `AGENTS.md` and `docs/WORKFLOW.md`; neither skills nor role names grant extra permissions.
