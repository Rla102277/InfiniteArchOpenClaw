# Build Slice

Read approved spec and architecture; inspect actual repository and git status first. Create an isolated feature branch (or worktree with user consent). Assign bounded files and tool permissions to the coding agent, prefer Codex when installed; Devin or Claude may be substituted. Write failing tests where practical, make minimal change, run all mandatory repo checks, then capture actual exit codes and evidence in feature docs. Do not treat a coding agent's self-assessment as proof. If tools/tests are blocked, report blocker and STOP rather than declaring done. Maximum three bounded repair rounds; no auto-merge or deployment.

## Completion contract

Show **what was observed**, **what changed**, **what is unverified**, and **what the owner decides next**. Follow `AGENTS.md` and `docs/WORKFLOW.md`; neither skills nor role names grant extra permissions.
